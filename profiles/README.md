# Accessibility profiles

Empty until Phase 4. Profiles are collections of interface preferences — not diagnoses.

Planned layout follows section 14 of the project plan:

```
visual/       large-text, high-contrast, colour-vision starting points
motion/       reduced-motion
motor/        large-targets
combinations/ curated starting points
```

Each profile carries a name, description, intended use, limitations, version, research references, and testing status. A profile is not promoted to "recommended" because a developer proposed it.
